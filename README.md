# 💈 Barbearia Navalha & Estilo

Landing page responsiva desenvolvida para apresentação de serviços, horários de atendimento e contato direto de uma barbearia.

> ⚠️ **Aviso:** Este é um projeto **demonstrativo** criado para fins de portfólio e estudo. Preços, avaliações, endereço, CNPJ e dados de contato exibidos são meramente ilustrativos.

## 🚀 Tecnologias Utilizadas

- **HTML5** (estrutura semântica e acessibilidade)
- **Tailwind CSS** (estilização e layout responsivo)
- **JavaScript** (interatividade e configurações dinâmicas)

## 📂 Estrutura do Projeto

- `index.html` — Página principal da barbearia
- `styles.css` — Estilos customizados
- `script.js` — Scripts e parâmetros da aplicação
